# Bradley Hagan Portfolio Website

This project is a multi-page website built with HTML, CSS, and JavaScript for GitHub Pages.

## Pages
- index.html
- about.html
- portfolio.html
- resume.html
- contact.html

## Important Google Form Note
The contact page includes an iframe placeholder. Before final submission, replace the iframe `src` value in `contact.html` with your own public Google Form embed URL. Make sure the form is set to "Anyone with the link" and test it in an incognito window.

## GitHub Pages Deployment
1. Create a new GitHub repository.
2. Upload all files from this folder.
3. Go to Settings > Pages.
4. Set the source to the main branch and root folder.
5. Save and copy the live GitHub Pages URL for Canvas.
